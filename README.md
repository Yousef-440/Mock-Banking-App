# Front-End Banking App (Mock)

A fully front-end simulated **banking application** built using **HTML**, **CSS**, and **Vanilla JavaScript**.  
It includes basic banking features with enhanced UI logic and session control

##  Login System

- Users can log in only with pre-defined accounts.
- No database or server used — authentication is simulated in JavaScript.

## Features

- **User Login** (Login with hardcoded accounts)
- **View Account Balance**
- **Transfer Funds** between predefined users
- **Transaction History** – displays all actions (deposits, withdrawals, transfers)
- **Loan Application** – users can apply for loans (mock process).
- **Account Deletion** – allows users to delete their account (hardcoded).
- **Session Timeout** – the app automatically logs out users after **5 minutes**

##  Technologies Used

- **HTML5** 
- **CSS3**
- **JavaScript**
